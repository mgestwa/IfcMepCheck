# BCF 2.1 XML schemas

`markup.xsd`, `visinfo.xsd` and `version.xsd` are unmodified copies of the BCF 2.1 schemas from
[buildingSMART/BCF-XML](https://github.com/buildingSMART/BCF-XML/tree/release_2_1/Schemas)
(branch `release_2_1`). They are used only to validate the exported BCF files in `tests/test_bcf.py`.
